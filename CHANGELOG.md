# Changelog

## 1.1.0 — 2026-10-26

- Блок E (структура SKILL.md): E1 frontmatter, E2 `name`, E3 качество `description`, E4 длина `description`, E5 порядок действий, E6 ссылки на файлы скилла. Каталог: `checks/E-skill-structure.md`.
- Блок F (безопасность): F1 секреты, F2 персональные данные, F3 prompt injection через внешний контент, F4 опасные действия без подтверждения. Каталог: `checks/F-security.md`.
- Блок G (ясность): G1 критерий, G2 формат результата, G3 условие остановки, G4 расшифровка терминов. Каталог: `checks/G-clarity.md`.
- Блок H (срабатывание скилла): H1 триггерные слова, H2 пересечение скиллов, H3 широкий триггер, H4 границы применения. Каталог: `checks/H-triggering.md`.
- `scripts/scan.py` 1.1.0: новые проверки E1, E2, E4, E6 (для `SKILL.md`), F1 (критично) и F2 (важно). Значения секретов, телефонов и почты маскируются во всех находках (первые 4 символа). F1/F2 проверяют и блоки кода.
- Тесты на новые проверки, маскирование, плейсхолдеры и защищённые блоки; фикстуры с заведомо фальшивыми ключами (`EXAMPLE`, `FAKE`).
- SKILL.md: каталог E–H в шаге 3, правило маскирования секретов в отчёте, обновлённый `description`.

## 1.0.0 — 2026-10-16

- Скилл `minga-prompt-audit`: блоки A (устаревшие приёмы), B (противоречия), C (мёртвые ссылки), D (дубли и раздувание).
- Отчёт по уровням важности с файлом, строкой, цитатой и общим diff; правки только по команде.
- Защищённые строки: `<!-- keep -->`, `<!-- keep:start -->…<!-- keep:end -->`.
- `scripts/scan.py` — детерминированный сканер без зависимостей (A1–A4, C1, C4, D1, D2, D4), вывод в Markdown или JSON.
- Тесты на эталонных «плохом» и «хорошем» наборах файлов.
