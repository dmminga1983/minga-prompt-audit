# minga-prompt-audit

**Аудит промптов и скиллов Claude: устаревшие приёмы, противоречия, мёртвые ссылки, раздувание, структура скилла, безопасность, ясность и срабатывание — с отчётом по строкам и готовым diff.**

Часть экосистемы [Minga](https://github.com/dmminga1983/minga). Скилл проверяет `CLAUDE.md`, `AGENTS.md`, `SKILL.md`, правила, команды, субагентов и системные промпты на то, что мешает современным моделям Claude: капс и давление, навязанные шаблоны рассуждений, правила, которые спорят друг с другом, ссылки на несуществующие файлы, дубли, сломанный frontmatter скилла, утёкшие секреты и персональные данные, размытые требования, скиллы, которые не срабатывают. Файлы не меняются, пока вы не скажете «применить».

## Чем отличается от встроенного `prompt-audit`

| | `/claude-api prompt-audit`, `/doctor prompt-audit` | minga-prompt-audit |
|---|---|---|
| Где работает | Claude Code CLI | claude.ai, Claude Code, любой агент со скиллами |
| Каталог проверок | не опубликован | открытый, с ID и примерами ([checks/](checks/)) |
| Русский язык | — | русские шаблоны давления и ролей, аббревиатуры (ГОСТ, СП, ЖК) не считаются капсом |
| Детерминированный сканер | — | `scripts/scan.py` без зависимостей + тесты |
| Защищённые строки | keep-list | `<!-- keep -->` и блоки `<!-- keep:start -->…<!-- keep:end -->` |

## Что проверяется (v1.1)

| Блок | Проверки |
|---|---|
| **A. Приёмы под старые модели** | A1 капс-давление · A2 угрозы и награды · A3 «думай пошагово» · A4 пустая роль · A5 повтор для надёжности · A6 абсолюты без причины · A7 только запреты |
| **B. Противоречия** | B1 в файле · B2 между файлами · B3 формат/язык · B4 неясный приоритет |
| **C. Мёртвые ссылки** | C1 файлы и `@импорты` · C2 команды и скрипты · C3 инструменты и скиллы · C4 устаревшие модели |
| **D. Дубли и раздувание** | D1 повторы · D2 длинные примеры · D3 очевидное · D4 слишком большие файлы |
| **E. Структура SKILL.md** | E1 нет или сломан frontmatter · E2 `name` не kebab-case или не совпадает с папкой · E3 расплывчатый `description` · E4 `description` длиннее ~1024 символов · E5 нет порядка действий · E6 ссылки на отсутствующие файлы скилла |
| **F. Безопасность** | F1 секреты (AWS, GitHub, Slack, ключи `sk-`, приватные ключи, `password = "..."`) · F2 персональные данные (телефоны, почта, паспорт, ИНН) · F3 выполнение указаний из внешнего контента (prompt injection) · F4 опасные действия без подтверждения |
| **G. Ясность** | G1 размытое требование без критерия · G2 нет формата результата · G3 нет условия остановки и момента для вопроса · G4 сокращения без расшифровки |
| **H. Срабатывание скилла** | H1 нет триггерных слов из реальных запросов (RU и EN) · H2 пересечение с другим скиллом в той же папке · H3 слишком широкий триггер · H4 не сказано, когда скилл не применять |

Подробные критерии — в [checks/](checks/), примеры «до/после» — в [examples/](examples/before-after.md).

Секреты и персональные данные в отчёте маскируются: видны только первые 4 символа.

## Установка

**claude.ai** — на странице репозитория нажмите *Code → Download ZIP* и загрузите архив в *Settings → Capabilities → Skills*.

**Claude Code** — склонируйте в папку скиллов:

```bash
git clone https://github.com/dmminga1983/minga-prompt-audit ~/.claude/skills/minga-prompt-audit
```

## Использование

Просто попросите:

> Проверь мой CLAUDE.md и скиллы на устаревшие промпты

> Сделай аудит `.claude/skills/report`

> Audit the system prompt in `src/agent.py`

Отчёт придёт по уровням 🔴 критично · 🟠 важно · ⚪ косметика, с файлом, строкой и цитатой, а в конце — общий diff. Ответьте «применить всё» или перечислите ID.

### Сканер отдельно

```bash
python3 scripts/scan.py                        # CLAUDE.md, AGENTS.md, SKILL.md и .claude/ в текущей папке
python3 scripts/scan.py .claude/skills/report  # конкретная папка
python3 scripts/scan.py --home --format json   # плюс ~/.claude, вывод в JSON
```

Сканер ловит механические проблемы: A1–A4, C1, C4, D1, D2, D4, E1, E2, E4, E6 (только для `SKILL.md`), F1 и F2. Противоречия (B), ясность (G), срабатывание (H) и остальные смысловые проверки (E3, E5, F3, F4) делает модель по скиллу.

### Защитить строки от аудита

```markdown
Эту строку не трогать <!-- keep -->

<!-- keep:start -->
ВЕСЬ ЭТОТ БЛОК ОСТАЁТСЯ КАК ЕСТЬ
<!-- keep:end -->
```
